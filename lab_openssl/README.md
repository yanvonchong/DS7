\# 📚 Descripción



Este laboratorio tiene como objetivo implementar funciones criptográficas utilizando la biblioteca \*\*OpenSSL\*\* en PHP para realizar procesos de:



\- 🔒 Cifrado

\- 🔓 Descifrado

\- 🔑 Generación de claves

\- 🛡️ Uso de IV dinámico

\- 📦 Conversión hexadecimal



\---



\# 🎯 Objetivo



Aplicar funciones criptográficas modernas utilizando OpenSSL en PHP para comprender el funcionamiento del cifrado simétrico mediante el algoritmo \*\*AES-128-CBC\*\*.
